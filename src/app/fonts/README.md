# Self-hosted brand fonts

These Latin WOFF2 subsets are stored here so local, CI, and production builds
do not depend on access to `fonts.googleapis.com`. The normal faces were
emitted by Next.js from the corresponding Google Fonts families; the Source
Serif 4 variable italic subset comes from Fontsource 5.3.0.

- Inter
- Poppins (600 and 700)
- Open Sans
- Source Serif 4
- Staatliches

The families are distributed under the SIL Open Font License 1.1. Canonical
sources and license files are available in the
[Google Fonts repository](https://github.com/google/fonts).
